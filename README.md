# 课程作业管理系统

## 项目简介

本课程作业管理系统是一个基于 Web 的综合实验项目，旨在实现教师发布作业、学生查看与提交作业的完整闭环。系统设计遵循人机交互（HCI）原则，注重用户体验和界面设计。

## 技术栈

- **前端**: HTML5 + CSS3 + JavaScript (原生)
- **图标库**: Tabler Icons
- **字体**: Google Fonts (Noto Sans SC)

## 功能模块

### 公共页面
- **P0: 登录页** - 支持教师/学生身份切换登录

### 教师端
- **P1: 作业列表页** - 查看已发布作业及提交进度
- **P2: 发布作业页** - 创建新作业（含附件上传）
- **P3: 提交情况页** - 查看学生提交详情

### 学生端
- **P4: 我的作业列表页** - 查看所有作业及状态
- **P5: 作业详情页** - 查看作业完整信息
- **P6: 提交作业页** - 上传作业文件

## 快速启动

### 方法一：直接打开

1. 在文件浏览器中找到 `src/pages/index.html`
2. 双击使用默认浏览器打开

### 方法二：使用本地服务器（推荐）

```bash
# 使用 Python 启动本地服务器
cd src/pages
python -m http.server 8080

# 或使用 Node.js 的 http-server
npx http-server -p 8080
```

然后在浏览器中访问：`http://localhost:8080`

## HCI 设计亮点

### 登录页
- ✅ 身份选择的视觉区分（教师/学生卡片切换）
- ✅ 错误提示友好性（明确告知错误原因）
- ✅ 忘记密码入口可见
- ✅ 默认焦点自动聚焦到账号输入框

### 教师作业列表页
- ✅ 系统状态可见性（进度条展示提交率）
- ✅ 紧急状态视觉区分（颜色标识）
- ✅ 空状态引导设计

### 发布作业页
- ✅ 分步骤引导（步骤条降低认知负荷）
- ✅ 防错原则（截止时间验证）
- ✅ 必填项标注（红色星号）
- ✅ 充分的提示文字

### 提交情况页
- ✅ 数据可读性（表格优化）
- ✅ 状态一致性（统一颜色语义）
- ✅ 筛选与搜索功能

### 学生作业列表页
- ✅ 进度可见性（倒计时 + 颜色预警）
- ✅ 通知徽章吸引注意力
- ✅ 一致性设计

### 作业详情页
- ✅ 信息完整性（所有信息在一页）
- ✅ 操作可达性（明显的提交按钮）
- ✅ 面包屑导航

### 提交作业页
- ✅ 操作可逆性（截止前可重提）
- ✅ 提交前检查清单（错误预防）
- ✅ 成功状态设计（显示时间戳和文件名）
- ✅ 下一步引导明确

## 注意事项

1. **数据持久化**: 当前版本使用内存存储，刷新页面后数据会重置
2. **文件上传**: 演示模式下文件上传为模拟，实际不会保存到服务器
3. **浏览器兼容**: 推荐使用 Chrome、Firefox、Edge 等现代浏览器
